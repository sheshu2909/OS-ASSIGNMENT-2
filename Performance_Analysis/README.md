# Performance analysis

`Measurement_Summary.md` states every measured quantity, the command that produced it and the platform caveat. `measurements.csv` holds the same numbers in machine-readable form. `Raw_Logs/` holds the unedited program transcripts, so any figure in the report can be traced back to the run that produced it.

Absolute timings were taken on the MSYS2 POSIX layer on Windows 11. Re-run the commands in the report's Appendix B on the lab machine before quoting absolute values; the ratios and the scaling trends are the part that transfers.
